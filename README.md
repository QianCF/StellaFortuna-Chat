# StellaFortuna-Chat
极其轻量、富文本极强、分片加载极好的私人聊天室。

富文本基于猎户座编辑器，支持其全特性。

支持引用跳转、搜索跳转。

消息加载是分片的，滚到哪加载到哪，不用担心消息多了以后加载困难。

滚动丝滑，不跳动，不闪烁，不卡顿。支持撤回消息。

支持上传文件拿url，然后可以写在链接和图片里。

index.php头部可以设置用户。

无任何外部依赖，粘贴文件后可在任何php服务器运行。

实时更新，不用担心漏掉消息，不需要刷新。

三路轮询，刷新视口、获取最新消息、拉取缺失消息互相独立。

无状态设计，每个请求都完全独立。

左上角欣欣聊天室字样点击来打开面板，内有导出聊天记录、桌面通知设定和黑夜模式设定。

带有字体面板，可以从服务器字体库下载，也可以本地选择
